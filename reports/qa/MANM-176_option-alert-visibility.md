# PR #143 — Manual signal tracking and post-T1 ATR trailing

- **Root cause:** `INSUFFICIENT_OPTION_RR` returned before lot calculation, hid the option fields and caused the dispatcher to reject trade registration. Manual signal tracking had been coupled to execution eligibility.
- **Fix:** Remove that R:R check entirely. Compute prices/lots before execution-only ordering checks and show calculated values independently of `is_valid`. Main registers every emitted, persisted signal as `SIGNAL_REFERENCE`, independently of capital/lots; it submits no new paper/broker entry orders. Missing quote/Greeks inputs remain unavailable.
- **ATR lifecycle:** T1 moves the spot stop to entry. Completed five-minute bars use Wilder ATR(5), HHV/LLV(10), multiplier 2.5. Check each close against the previously active stop first, then tighten the stop for subsequent bars. CE exits strictly below; PE strictly above. Ignore wicks/equality, never loosen, retain entry during warmup, and keep T2 as a displayed reference. Persist stop/state/watermarks; restore them across restart. ATR signal exits are recorded at the completed close using the 50% T1/runner spot model and score 1. Paper exits remain pending until an observed bid; option estimates do not establish fills.
- **Changelog verification:** The old Dynamic Trailing Stops entry and commit `458b23b` implemented T1-to-entry break-even. ATR commits `6a681b3`, `12f0d4f`, `d76594f`, `60bea2c`, and `cc80a8e` changed documentation only; the later roadmap explicitly deferred ATR. This PR adds the actual runtime feature.
- **Regression scope:** Real main-loop bearish TREND_CONTINUATION with poor theta-adjusted R:R, zero/funded capital, actual pricing and mocked Discord payload; missing/invalid data still permits manual tracking; no new order submission. Both completed-history monitors run before normal/final-bar chain failures. Math, both directions, warmup/gaps, duplicates, ignored wicks/T2, strict closes, ratchets, same-candle entry protection, restart restoration, persistence failure/retry, terminal repair, ML row retention and alert wording are covered.
