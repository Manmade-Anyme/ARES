# Domain Models

ARES uses strict Python `dataclasses` and Enums to ensure robust state management and memory efficiency. These are defined in `models.py`.

## Core Enums

### `SetupType`
Defines the core setups detected by the ARES system.
- `FAILED_BREAKOUT`
- `OI_WALL_REJECTION`
- `EXHAUSTION_REVERSAL`

### `Direction`
Indicates the directional bias of the detected trading signal: `BULLISH` or `BEARISH`.

## Core Dataclasses

### `OHLCVCandle`
Represents a single 1-minute price candle for NIFTY 50. Includes an incrementally calculated VWAP.
- `timestamp: datetime`
- `open, high, low, close: float`
- `volume: int`
- `vwap: float`

### `OptionRow`
Represents a single option contract (CE or PE) at a specific strike price. Vital for detecting OI walls and IV crushes.
- `strike: int`
- `option_type: str` (CE or PE)
- `ltp, iv: float`
- `oi, oi_prev: int`
- `oi_change_pct: float`
- `gamma, theta: float`

### `ATMStrikes`
Holds the current At-The-Money (ATM) context.
- `spot_price: float`
- `ce: OptionRow`
- `pe: OptionRow`

### `ResistanceLevel`
Represents a significant price level on the chart that acts as support or resistance. Built from PDH/PDL or massive OI walls.
- `price: float`
- `source: str`
- `strength: int` (1 to 3)

### `AresSignal`
The complete trade signal package generated by the [[04_Engine]].
- `setup_type: SetupType`
- `direction: Direction`
- `trigger_price: float`
- `entry_zone: Tuple[float, float]`
- `stop_loss, target_1, target_2: float`
- `confidence: str`
- `reasons: List[str]`
- `timestamp: datetime`
- `strike_to_trade: int`
- `option_type: str`
